# Example RabbitMQ Connection

A typed connection to a RabbitMQ broker (AMQP 0-9-1). This sample points at a local
broker with the default `guest` credentials and management API on `:15672` — swap in
your own broker's host, vhost, and credentials for a real deployment.

See [`example-rabbitmq.connection.yaml`](./example-rabbitmq.connection.yaml).
