# What is a folio?

A folio is Zenvara's knowledge-base entity — a titled Markdown concept that lives
alongside flows, skills, and templates in the same version-controlled storage.
Folios are how you keep reference material (runbooks, explanations, onboarding notes)
next to the automation that uses it, retrievable through the same entity surface as
everything else.

See [`what-is-a-folio.folio.md`](./what-is-a-folio.folio.md) — the YAML frontmatter
and the document body sit together in that one file, right beside this sidecar.
