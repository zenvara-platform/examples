# What is a folio?

A folio is Zenvara's knowledge-base entity — a titled document (`document.md`) that
lives alongside flows, skills, and templates in the same version-controlled storage.
Folios are how you keep reference material (runbooks, explanations, onboarding notes)
next to the automation that uses it, retrievable through the same entity surface as
everything else.

See [`what-is-a-folio.folio.yaml`](./what-is-a-folio.folio.yaml) and its document at
[`../folio-documents/what-is-a-folio.md`](../folio-documents/what-is-a-folio.md).
