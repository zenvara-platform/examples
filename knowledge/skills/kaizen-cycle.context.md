# Kaizen Cycle (PDCA)

A skill guides a user through a disciplined, repeatable methodology rather than
executing a fixed pipeline. This one walks one full Plan-Do-Check-Act improvement
cycle on any stated goal: go and see, measure the current state, find the root
cause, run one small experiment, and capture the result as a measured A3 roadmap
with a recommended next step.

**Category:** methodology
**Tags:** kaizen, pdca, continuous-improvement, lean, a3, methodology
