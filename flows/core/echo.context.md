# Echo

Zenvara can be invoked via MCP and returns structured output with system context fields

**Connectors:** none — self-contained  
**Capabilities:** parameter-passing, mcp-connectivity  
**Domain:** core

**What to look for when you run it:** output.echo = 'Parameters received successfully'; output.invocation-id and output.flow-name are populated

See [`echo.flow.yaml`](./echo.flow.yaml) for the full definition.
